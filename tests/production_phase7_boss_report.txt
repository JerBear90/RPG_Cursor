4. Solar Heart unlock flow
--------------------------

Mirror B → heat vents disabled + barrier B removed
Mirror C → glass pulse disabled + inner gate opened
All three → puzzle_completed + cooling_channels_active → `unlock_solar_heart_chamber()`
Seal retracts (sand wall removed); chamber accessible; boss arena trigger starts encounter.

-----------------------------

Mirror B: disables boss arena heat-vent lane

------------------

15. Death-reset flow
--------------------

hazards/summons/beams cleared; arena gate released; in_boss_fight cleared.
