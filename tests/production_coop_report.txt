## Input Routing

* P1: default InputMap actions + keyboard/mouse
* P2: `p2_*` actions (arrows + controller device 1)
* Dialogue confirm/cancel routes via `interacting_player_index`
* Field revive uses `interact` / `p2_interact` hold

## Shared Camera

* Solo: OTS attach unchanged
* Co-op: midpoint of all registered players (includes downed)
* Dynamic zoom: `coop_min_back` 2.73 → `coop_max_back` 6.8
* Separation multiplier: `coop_zoom_separation` 14.0
* Smooth speed: `coop_zoom_smooth_speed` 0.1

* Soft tether cap: `coop_soft_tether_distance` 18.0

---

## Spawn & Death

* P1 at marker; P2 at validated companion offset
* Single death: downed/inactive, no level restart
* Party wipe: existing restart for both with offsets
* Field revive: 35% HP (`FIELD_REVIVE_HP_RATIO`)
* Camp/transition/checkpoint revive: 45% HP

---

## Field Hold-to-Revive

* Range: 2.25m (`FIELD_REVIVE_RANGE`)
* Hold: 2.0s (`FIELD_REVIVE_HOLD_SEC`)
* Revive HP: 35%
* Cancels on: out of range, damage to reviver, attack/dodge/jump/spell, menu/dialogue, release interact
* Prompts: player-specific via `GameManager.coop_player_prompts`
* Progress shown as percentage in prompt text

---

## HUD

* P1 vitals/layout: unchanged
* P1 downed: `Player 1 Downed | Waiting for Revive` on interact prompt
* P2 vitals: compact HP/MP/ST in top-left
* P2 actions: `P2ActionLabel` — Light/Heavy/Spell/Dodge/Interact bindings
* P2 downed: `P2 Downed | Waiting for Revive`
* P2 revive: `Hold [key] Revive Player N (XX%)`
* Minimap: P1 arrow + P2 blue dot

---

## Interaction Ownership

* `interacting_player_index` set in `InteractableBase.interact()` and `player_interaction`
* Dialogue confirm blocked for non-owner (P2 uses p2_interact / joypad 1)
* Resets to 0 on dialogue close
* Co-op field-revive prompts take priority over world interact prompts

## Enemy Targeting

* `EnemyBase._pick_nearest_living_player()` — closest living player in range
* Ignores downed players
* Target switch cooldown: 1.0s
* Switches when another player is ~28% closer (`TARGET_SWITCH_CLOSER_RATIO` 0.72)
* Damage aggro validates living target

## Known Limitations

* P2 does not have a full duplicate ability bar (compact action line + level/XP line only)
* XP/stats remain per-player `StatsComponent` (not merged into a single party level)
* P1 XP bar reflects P1 only; P2 uses compact `P2 Lv | XP` line (no full XP bar)
* Online multiplayer and split-screen not in scope
* Hold-to-revive progress uses text percentage (polished copy), not a dedicated progress bar widget
* Pickup toasts throttle duplicates but do not batch `Wood x10` style aggregation yet
* P2 compact HUD sits below P1 vitals block; very small viewports may need manual UI scale tweak
* Some environmental weather controllers may still gate on P1-adjacent logic only
* Dungeon spawn scripts use simple i×2 offset rather than `get_party_offset`
* Enemy target indicator UI not added (enemies face/aim via existing `PlanarFacing` only)
* Boss arena co-op entry pulls distant P2; does not block entry if P2 is downed outside arena
* Item Box deposit is one item per confirm (camp chest has deposit-all + full-stack)
* Older v2 co-op saves load P2 at level 1 until re-saved as v3 with P2 progress
* Waystone travel pulls distant living companions rather than hard-blocking until both stand at stone (pull message shown when applicable)
