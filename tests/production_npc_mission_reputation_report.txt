## Changes Summary

### Resource & Registry Layer
* `npc_data.gd`, `npc_mission_data.gd`, `dialogue_data.gd`, `npc_relationship_data.gd`
* `npc_mission_registry.gd` — static mission metadata and NPC→mission mapping

### Autoload Managers
* **NpcStateManager** — shared relationship score, anger state, fines, gifts, service locks; save/load
* **NpcMissionHooks** — objective hooks for resources, base upgrades, pets, waystones, bandit kills

### Prototype NPC Missions (QuestManager)
1. **Rebuild the Forge** (`bram_ironhand` / Old Blacksmith) — iron scrap x6, fire resin x1, turn-in
2. **Clear the Bandit Path** (`wounded_scout`) — defeat 5 bandits, return
3. **Build the Basics** (`quartermaster_vale` / Camp Builder) — workbench L2, water L1, garden L1, turn-in
4. **A Hound in the Ash** (`beast_handler`) — Beast Bond, pet shelter L1, bone x3, adopt Ash Hound, turn-in
5. **Wake the Stone** (`waystone_keeper`) — find waystone, crystal shard x3, activate, turn-in

### NPC Anger & Relationship
* Anger states: calm → annoyed → angry → hostile
* Hit reactions with dialogue lines; achievement on first annoy
* Repair: pay fine (scaled copper), gift (herb, bandage, pet treat, repair kit, gems)
* Hostile blocks shop; fine reduces hostile → angry (not permanent soft-lock)
* Relationship labels: Hostile, Angry, Wary, Neutral, Friendly, Trusted
* Friendly Old Blacksmith: repair discount display; merchant relationship price multiplier

### Scene / NPC Updates
* Hearthhold: Old Blacksmith, Camp Builder use `hearthhold_npc.tscn` with mission flow
* Added **Beast Handler** and **Waystone Keeper** at Hearthhold Camp
* **Wounded Scout** (Darkpine) uses `hearthhold_npc.gd` for Clear the Bandit Path

### Integration Hooks
* `RegionContent.on_enemy_killed` → `NpcMissionHooks.on_enemy_killed`
* `waystone.gd` first activation → `NpcMissionHooks.on_waystone_activated`
* `player_skill_tree.gd` Beast Bond unlock → mission objective sync
* `SaveManager` persists `npc_states`; `GameManager` resets on new game
* Merchant shop applies relationship price multiplier

### Toasts
* `Mission Accepted: …`, `Objective Complete: …`, `Mission Complete: …`
* `Relationship repaired`, `Paid fine: …`, `Gift accepted`, `Gift refused`

## Cross-Pass Summary: Quest / Map / Tracker (2026-06-10)

A follow-up pass added the player navigation layer on top of this NPC mission foundation:

* **ObjectiveRouter** autoload resolves mission objectives to world targets (NPC, station, waystone, boss, region hints)
* **Quest tracker HUD** shows tracked mission, objective, progress, distance (nearest living player in co-op), and input hints
* **Quest tracker screen** lists missions with status/rewards; track on confirm; menu ownership via `GameManager.menu_owner_index`
* **World map** shows region danger/level, P1/P2/pet/objective/NPC/waystone/boss markers on a functional canvas
* **Save/load** preserves tracked quest; deserialize refreshes routing via `tracked_quest_changed`

## Known Limitations (After This Pass)

* No massive branching story — single-offer missions per NPC
* Apology tasks (gather wood/bandage) not fully wired — fine and gift repair primary
* Time-based anger decay not implemented (no day/night decay system)
* Faction-wide reputation not implemented — per-NPC relationship only
* Only five prototype missions; Silent Merchant / Mask Collector / Wandering Survivor not mission-enabled yet
* Relationship repair discount on forge upgrades is display-first; full craft cost integration partial
* Pet accidental friendly fire does not anger NPCs (by design — player hits only)
* Legacy `merchant_errand` quest still exists for older saves; Wounded Scout primary mission is Clear the Bandit Path
* Only Ash Hound pet mission integration
* Co-op shared party relationship (not per-player reputation)
* Map/tracker layer is functional foundation — see `production_quest_map_tracker_report.txt` for map/tracker-specific limits
