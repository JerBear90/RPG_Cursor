## Changes Summary

### Focus Resource (`focus_component.gd`)
* `max_focus`, `current_focus`, `regen_rate`, `focus_regen_delay`, `focus_cost_multiplier`
* Regen pauses until delay elapses after spending Focus
* Serialize/deserialize for save/load; current Focus restored after derived stat recalc
* P1/P2 independent pools; Amethyst gem + Spirit stat + Arcane Focus skill feed max Focus

### Spell System
* New scripts: `spell_data.gd`, `spell_registry.gd`, `spell_caster.gd`, `spell_cooldown_manager.gd`, `spell_area_effect.gd`, `spell_tree_controller.gd`
* `player_spellcaster.gd` refactored to use registry/cooldown/selection helpers
* Four prototype spells with prompt values:
  * **Ember Bolt** — fire projectile, 15 Focus, 1.2s CD, 12 dmg + Int scaling
  * **Healing Mist** — 4m radius heal, 25 Focus, 8s CD, 20 HP + Spirit scaling, heals co-op ally
  * **Venom Dart** — poison projectile, 18 Focus, 2s CD, 8 dmg + 4-tick poison DoT
  * **Shadow Lash** — 5m cone dark strike, 22 Focus, 4s CD, 18 dmg + Int scaling
* Cast toasts: `P1 cast Ember Bolt`, `P2 No Focus`, `Spell Cooldown`, `Spell Locked`

### Skill Tree (`player_skill_tree.gd`)
* Ranked nodes (`node_ranks`) with max ranks; legacy nodes preserved for older saves
* Prototype branches: Combat Mastery, Survival, Crafting, Fire, Water, Poison, Dark, Co-op Support
* Prototype nodes: Sharpened Strikes, Guard Discipline, Scavenger Eye, Field Dressing, Efficient Repairs, Socket Apprentice, spell unlocks, Ember Control, Soothing Flow, Toxic Handling, Hollow Focus, Reviver's Resolve, Shared Recovery
* Passive integration: weapon damage, block stamina, repair cost, socket prep cost, revive hold, camp rest bonus, spell damage/heal/focus/cooldown modifiers

### Skill Resources
* `skill_node_data.gd`, `skill_branch_data.gd`, `skill_tree_data.gd` — Godot Resource schemas for future data-driven trees

### Stat Points
* Six stats (Strength, Dexterity, Intelligence, Vitality, Endurance, Spirit) spendable from skill tree panel
* Level-up grants +1 stat point and +1 skill point per player
* Derived stats refresh on spend (HP, Stamina, Focus)

### UI
* Skill tree panel (K key): rank display, branch info, stat allocation with current values
* Spell wheel + quick-spell cycle preserved
* Focus orb (ManaOrb), spell slot cooldown/insufficient Focus highlight
* P2 compact vitals include Focus; hidden in solo

### Save / Load
* Focus current/max, spell unlocks/selection, skill node ranks, stats — per-player in co-op
* Older saves migrate `unlocked_nodes` array to rank 1; missing fields default safely
