## Changes Summary

### Resource Node Visual Placeholders
* Added `scripts/resources/resource_node_visual_factory.gd` with 13 lightweight primitive mesh types
* `ResourceNode` builds visuals via factory instead of generic colored spheres
* Types: fallen log, tree stump, herb bush, berry bush, mushroom cluster, stone pile, ore vein, crystal node, scrap heap, bone pile, water spring, corrupted root, fire resin growth

### Interaction Prompt Clarity
* Gather prompts use readable labels (`Gather Herbs`, `Gather Crystal Shards`, etc.)
* `CoopUiCopy.press_prompt()` wraps all interactable prompts (P1: Press E — … / P2: Press A — …)
* Depleted nodes show `Depleted` only
* Missing tool shows toast: `P1: Requires Pickaxe`

### Depleted / Destroyed Persistence
* `WorldStateManager` tracks `depleted_resource_nodes` and `destroyed_world_objects`
* Serialized in save v3 `world_state` block; backward-safe defaults on missing keys
* Important nodes use stable IDs (`region:node_id` format)
* Persisted spawns: Darkpine fire resin, Rotfen mire crystal, Ashfall ember crystal, Frostgrave glacial crystal, Blightreach viridian crystal + corrupted root
* Generic herbs/berries/stone and random crates/barrels remain non-persistent

### Water Collector & Garden Plot
* Scenes: `scenes/base/water_collector.tscn`, `scenes/base/garden_plot.tscn`
* Placed in Hearthhold Camp (`Level/Stations`)
* Level 0: interact opens upgrade menu with material requirements
* Level 1+: Collect Water (dirty/purified by level) / Harvest Herbs (herbs/berries by level) with 45s cooldown
* Upgrade consumes inventory + base storage; level persists via `BaseManager`

### Missing Material & Tracking Polish
* Upgrade/craft checks use `InventoryManager.get_combined_count()` (inventory + base storage)
* Missing messages use `ItemDatabase.get_display_name()` and readable currency (`Need 2 Silver`)
* Progress toasts for Workbench L2, Forge L2, Water Collector, Garden Plot, Pet Shelter, Mask Stand
* Updates on P1/P2 gather, deposit, camp chest deposit-all, and inventory changes
* Completion toast: `{Station} materials complete` + `Return to Hearthhold Camp`
