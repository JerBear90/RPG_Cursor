## Changes Summary

### Objective Routing Foundation
* `scripts/navigation/objective_target.gd` — target data (id, type, region, position, hints)
* `scripts/navigation/map_icon.gd` — map icon types and colors
* `scripts/navigation/map_region_data.gd` — region level/danger labels and summaries
* `scripts/navigation/objective_marker.gd` — optional world marker node
* `scripts/autoload/objective_router.gd` — autoload routing table, distance (nearest living player), map icons, waypoint sync

### Quest Tracker HUD
* `ui/components/quest_tracker.gd` — "Tracked:" title, objective, progress, distance, input hints
* `scripts/ui/game_hud.gd` — HUD updates via ObjectiveRouter; D-pad L/R cycles tracked mission; View opens map; quest tracker screen integration

### Quest Tracker Screen
* `ui/map/quest_tracker_screen.gd` + `.tscn` — mission list with status labels (Available / Active / Ready to Turn In / Completed / Locked), objectives, reward preview, NPC giver, region hint, track on confirm

### World / Region Map
* `ui/map/world_map.gd` + `.tscn` — region list with danger/level, legend, detail panel
* `ui/map/map_canvas.gd` — functional region map drawing with icon markers
* `ui/map/minimap.gd`, `minimap_marker_service.gd` — ObjectiveRouter distance and tracked position

### QuestManager Extensions
* `get_tracked_display_title()`, `get_current_objective()`, `get_quest_status()`, `get_reward_preview_text()`
* `cycle_tracked_quest()`, `clear_tracked_quest()`, tracked-mission toast on manual track
* Save/load emits `tracked_quest_changed` after deserialize for routing refresh

### Notifications (NpcMissionHooks)
* Mission Accepted, Objective Updated (count progress), Objective Complete, Mission Ready, Mission Complete
* Registry missions skip duplicate quest toasts in game_hud

### Routing Table (Prototype Missions + Legacy)
* NPC turn-ins, base stations, waystones, resource hints, bandit group, boss, quest destinations
* Cross-region objectives show region hint instead of broken distance
* Missing targets fail safely (text only, no crash)
