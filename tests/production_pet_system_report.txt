## Changes Summary

### Beast Bond Skill Branch
* **Beast Bond** — unlocks pet system access (level 3, 1 SP)
* **Loyal Companion** — +10 pet max HP per rank (max 2)
* **Scavenger Nose** — +10% pet resource find per rank (stored/display)
* **Pack Tactics** — +5% pet damage vs shared target per rank (max 2)
* **Quick Recall** — faster pet recall speed (max 1)
* Legacy **Wolf Bond** preserved — also grants Beast Bond access

### Pet Shelter (Hearthhold Camp)
* Requires Beast Bond + Pet Shelter Level 1 upgrade (Wood x8, Cloth x4, Hide x2, Bone x3, 20 copper)
* Interact: adopt/summon Ash Hound, recover downed pet
* Removed auto-unlock on Hearthhold region entry
* Toasts: `Beast Bond Required`, `Pet Shelter Level 1 Required`, `P1 adopted Ash Hound`, `Pet summoned`

### Shared Party Pet Architecture
* One active party pet (Ash Hound) — avoids co-op crowding
* Follows party center; warps if >15m; stuck recovery after 3s
* Commands: Follow, Stay, Attack, Defend, Recall (pet wheel / D-pad Down)
* Stats: 60 HP, 6 damage, 1.5s attack CD, 8m detection, 2.5m follow distance

### Pet Scripts
* `pet_data.gd`, `pet_gear_data.gd`, `pet_stats.gd`, `pet_ai.gd`, `pet_controller.gd`
* `ash_hound.gd` extends pet controller
* `pet_shelter.gd` — shelter requirement helpers
* `pet_command_wheel.gd` — alias for command wheel UI

### Pet Combat
* Pet in `"pet"` group; hurtbox team `"pet"`, hitbox team `"pet"`
* Takes damage, can be downed (not permanently killed)
* Recovers at camp rest, Pet Shelter interact, or shelter recovery action
* Does not drain player weapon durability

### Pet Gear (placeholder)
* Items: Ash Collar (+10 HP), Bone Charm (+1 dmg), Small Pack (+discovery display)
* `PetManager.equipped_gear_id` applies modifiers when set

### Pet HUD
* Compact status label: `Ash Hound | HP 42 / 60 | Follow`
* Hidden when no active pet
* Downed/recovered toasts

### Save / Load
* Beast bond flag, adopted pets, active pet ID, names, HP/downed state, command, gear
* Legacy `unlocked` array migrates to adopted pets
* Pet respawns near party on level load

## Known Limitations (Post-Pass)

* Only Ash Hound implemented (Grove Fox, Bone Raven, etc. not built)
* One shared party pet — not per-player pets
* Scavenger Nose resource find is stored/display only
* Pet gear equip UI is placeholder — items exist, manual `equipped_gear_id` only
* Pet uses placeholder German Shepherd mesh, not custom ash-gray art
* No pet breeding, leveling, or multiple active pets
* Pet wheel gamepad-only (D-pad Down hold); no keyboard bind yet
* No automated tests added
