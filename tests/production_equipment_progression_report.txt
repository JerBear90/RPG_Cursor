## Changes Summary

### Equipment Durability Foundation
* New autoload: `scripts/autoload/equipment_manager.gd`
* Gear instances track: `current_durability`, `max_durability`, `upgrade_level`, `reinforcement_level`, `socket_count`, `max_socket_count`, `socket_prep_level`, `socketed_gems`, `is_broken`, `instance_id`
* Tier-based max durability via `ItemDatabase.get_max_durability()` (weapons 40–100, armor 70, shields 80)
* Durability loss: weapon hits (-1), shield blocks (-1 to -3), armor damage taken (-1 random piece), tool gather (-1)
* Broken gear reduces effectiveness to 50%; badly worn (≤25%) reduces to 75%
* Gear never disappears at zero durability

### Repair System
* Workbench/Forge crafting menus include per-item **Repair** actions (resource cost from inventory + base storage)
* **Repair Kit** consumable restores 35 durability or 40% (whichever is higher)
* Repair Kit targets first damaged equipped item, then first damaged inventory gear
* Kit is not consumed if no valid damaged target exists
* Toasts: `P1 repaired Rusty Sword`, `Missing Metal Scraps x2`, `Item is already fully repaired`

### Craft Integration
* `repair_kit` recipe unchanged (iron_scrap x2, cloth_scrap x1, oil x1, 10 copper)
* `basic_weapon_upgrade` → weapon_upgrade_kit (Workbench L2)
* `armor_reinforcement` → armor_reinforcement_kit (Forge L2)
* Kits apply +1 upgrade/reinforcement to equipped weapon/chest armor when used from inventory

### Weapon Upgrade (+1 prototype)
* Workbench menu: Upgrade weapon (iron_scrap x5, weapon_parts x1, 25 copper) OR use kit
* +12% effective damage per level, +5 max durability
* Requires Workbench L2 for +1; max +3 defined (only +1 wired)

### Armor Reinforcement (+1 prototype)
* Forge menu: Reinforce armor (hide x2, armor_plates x1, iron_scrap x3) OR use kit
* +12% effective armor HP per level, +5 max durability
* Requires Forge L2; max +3 defined (only +1 wired)

### Socket Preparation (Forge L2)
* **Prepare Socket** action: crystal_shard x2, iron_scrap x2, 1 silver (100 copper)
* Increments `socket_count` by 1 up to `max_socket_count`
* `socketed_gems` placeholder array reserved for future gem pass
* No gem insertion yet

### UI & Co-op
* Inventory panel shows durability, upgrade/reinforcement level, socket count, repair preview
* Workbench/Forge menus list equipment actions with requirement status
* Menu owner attribution on all repair/upgrade/reinforce/socket toasts
* Shared inventory/resources; solo behavior unchanged

### Save / Load
* Gear instance fields serialize through existing `InventoryManager.serialize()` items array
* `EquipmentManager.normalize_all_items()` + `migrate_equipment_slots()` on load
* Older saves default missing durability fields safely

* No automated tests added
