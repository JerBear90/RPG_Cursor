## Resource Loop Overview

Explore → destroy props → gather nodes → shared inventory → deposit at camp/base → craft → upgrade stations → prepare for next region.

---

## Destructible Objects

### Core System

* `DestructibleObject` — HP-based break via combat hurtbox; one-time `_destroyed` guard prevents duplicate drops
* Direct grant path uses `ResourceFeedbackManager.notify_player_pickup()` with attacker attribution
* Loot table path uses `LootManager.drop_loot_table()` → world pickups with co-op P1/P2 toasts

### Drop Tables (LootManager)

| Table ID | Drops |
|----------|-------|
| `destructible_crate` | Wood 1–3, Nails 0–2, Copper 0–8, small food chance |
| `destructible_barrel` | Wood 1–2, Waterskin, Cloth, Copper |
| `destructible_furniture` | Wood 2–4, Cloth 0–2, Nails 0–2 |
| `destructible_scrap` | Iron Scrap 1–4, Wire, Bolts, rare Weapon Parts |
| `destructible_bone` | Bone 1–4, Hide, rare Charm Fragment |
| `destructible_crystal` | Crystal Shard 1–3, Crystal Dust 0–1 |
| `destructible_corrupted_root` | Corrupted Roots 1–3, Poison Gland, Fiber |
| `destructible_rock` | Stone 1–3 |

### Prop Factory (Kenney meshes)

Barrel, scrap, bone, crystal, corrupted root, furniture/cart, rock mappings added to `DestructiblePropFactory`.

### Region Spawns

* Darkpine Forest: crates, barrel, scrap pile, herb/berry/stone gather nodes
* Existing crate/herb destructible scenes in bandit camp, ruined watchtower, hearthhold

## Resource Node Gathering

### Core System (`ResourceNode`)

* InteractionArea (layer 32) for player detect
* Simple colored visual marker per resource type
* Co-op gather lock (`_gathering`) prevents double collection
* `ResourceFeedbackManager.notify_player_gathered()` — `P{n} gathered {item} x{qty}`
* Optional `requires_tool` with readable missing-tool toast
* Depleted state hides visual; prompt becomes `Depleted`
* Quest hooks via `RegionContent.on_resource_gathered()`

### Runtime Nodes

All region `_spawn_resource()` calls now create fully interactable nodes (Rotfen, Ashfall, Frostgrave, Coast, Blightreach, Ember Wastes, Sunless Dominion, Darkpine).

## Resource Item Definitions

New core materials added to `ItemDatabase`:

Natural: fiber, berries, mushrooms, hide, bone, raw_meat, cooked_meat, dirty_water, seeds, charcoal, firewood

Scrap: wire, bolts, rope, leather_strips, broken_blade, weapon_parts, armor_plates, oil, gears

Rare: crystal_shard, crystal_dust, fire_resin, corrupted_roots, silver_ore, charm_fragment

Craft outputs: fire_coating, pet_treat, weapon_upgrade_kit, armor_reinforcement_kit

All typed as `material` or `consumable`; stackable; depositable to base storage.

## Co-op Safety

* Destructible destroy guard is per-object (no duplicate drops from simultaneous hits)
* Gather nodes use `_gathering` lock
* Pickup/gather toasts attribute P1/P2
* Crafting/upgrades consume shared inventory once; owner attribution on craft/upgrade toasts
* Menu ownership unchanged from co-op polish pass

---

## Save / Load

* Shared inventory, base storage, station levels serialized via existing SaveManager v3
* Destructible/resource nodes respawn on region reload (no persistent depletion save — by design for prototype loop)

## Known Limitations

* Resource visuals are lightweight primitive placeholders — final art per type still pending
* Water Collector / Garden Plot production uses a 45s cooldown (no rest-cycle timing yet)
* Water Collector L2 / Garden Plot L2 upgrade tiers not yet defined
* Important destructible persistence IDs assigned for runtime resource nodes; scene-placed props not yet flagged
* Pickup batching still throttles rather than aggregates (`Wood x10`)
* Tool requirements are lightweight (inventory/equipment check, not dedicated tool items)
* No new regions added — loop uses existing Phase 0–8 areas
