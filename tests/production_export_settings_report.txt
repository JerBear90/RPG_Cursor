| Platform | Resolved path |
|----------|---------------|
| Windows | %APPDATA%\Godot\app_userdata\Exiled Survivors\saves\ |
| Linux | ~/.local/share/godot/app_userdata/Exiled Survivors/saves/ |
| macOS | ~/Library/Application Support/Godot/app_userdata/Exiled Survivors/saves/ |

This path is standard Godot user:// behavior and should work in exported builds
without code changes. Verify once after first Windows/Linux export.
