## Changes Summary

### Tutorial Prompt Layer
* `tutorial_prompt_manager.gd` — one-time toasts for movement, camera, interact, combat, dodge, block, gather, destructibles, inventory, crafting, quest tracker, map, waystone, camp rest, co-op revive, pet, spellcasting
* Seen state persists in save/load
* Keyboard + controller labels via `UiInputLabels`

### Vertical Slice Flow
* `vertical_slice_flow.gd` — opening intro copy, hearthhold arrival hint, blacksmith guidance, demo completion messages
* Milestone autosave hooks (hearthhold arrival, mission accept, quest complete, waystone unlock)
* Demo complete after `rebuild_the_forge`, `wake_the_stone`, `clear_bandit_path`, or Bandit Captain defeat

### New Game Opening
* Intro toast on first spawn (solo + co-op variants)
* Opening quest `find_wolf_crest` now has two steps: **Reach Hearthhold Camp** → **Find the Wolf Crest Shrine**
* Hearthhold region entry advances first objective and shows blacksmith hint

### Starting Gear
* Auto-equip rusty sword + traveler cloak
* 2 bandages in quick slot 0
* Existing rations, waterskin, wood, stone, 50 copper preserved

### Objective Routing Polish
* Hearthhold gate route for opening objective
* Resource hints: "Search Darkpine Forest for Metal Scraps / Fire Resin"
* Wounded Scout fallback position corrected to scene coords
* Crystal shard region hint improved

### Early Content Placement (Darkpine)
* Extra crates, barrels, scrap piles near outpost path
* Second fire resin node near spawn route
* Tutorial **Raider Trainee** (low HP/damage) near outpost

### Save / Continue
* `SaveManager.try_milestone_autosave()` — autosaves to slot 0 on milestones
* Tutorial + vertical slice state in save payload
* `WaystoneManager.reset_for_new_game()` fully resets `hearthhold_unlocked`

### Integration Hooks
* Player movement/combat/interact, camera, destructibles, resources, camps, waystones, workbench/forge, pet shelter, spell cast, co-op revive, map/quest/inventory menus
